
# PUZ Store — متجر رقمي قابل للاستضافة الذاتية

متجر عربي بهوية سوداء/حمراء/سماوية، لوحة تحكم للمنتجات، رفع ملفات، دفع عبر Moyasar، وتسليم رابط تنزيل مؤقت بعد التحقق من الدفع.

## الملفات
- `public/`: واجهة المتجر ولوحة التحكم وصفحة نتيجة الدفع.
- `functions/`: واجهات API على Cloudflare Pages Functions.
- `schema.sql`: جداول D1.
- `wrangler.toml`: ربط D1 وR2 (ضع معرّف قاعدة البيانات).
- `README.md`: دليل النشر.

## قبل النشر
هذا مشروع بداية قابل للتخصيص، وليس خدمة جاهزة مفعلة. لا يمكن استقبال أموال حقيقية قبل فتح حساب تاجر لدى Moyasar واجتياز التحقق وتفعيل طرق الدفع. الرسوم والقبول التجاري وموعد التسوية يحددها مزود الدفع. تحقق منهم مباشرة من مدى وApple Pay وSTC Pay؛ ظهور وسيلة الدفع في الكود لا يعني أنها مفعّلة لحسابك.

## 1) أنشئ الموارد على Cloudflare
1. أنشئ حساباً في Cloudflare.
2. أنشئ D1 database باسم `puz-store`.
3. نفّذ `schema.sql` على قاعدة البيانات.
4. أنشئ R2 bucket باسم `puz-store-files`.
5. ضع معرّف D1 الحقيقي في `wrangler.toml` بدلاً من `REPLACE_WITH_YOUR_D1_DATABASE_ID`.
6. ارفع المجلد إلى GitHub ثم اربط المستودع بمشروع Cloudflare Pages. اختر الجذر `puz-store` ومجلد الإخراج `public`.
7. في Pages > Settings > Bindings تأكد من ربط:
   - D1 باسم `DB`
   - R2 باسم `BUCKET`
   ثم أعد النشر.

## 2) أضف الأسرار والمتغيرات
من Pages > Settings > Variables and Secrets أضف:
- `MOYASAR_SECRET_KEY` (Secret)
- `MOYASAR_PUBLISHABLE_KEY` (Variable)
- `ADMIN_PASSWORD_HASH` (Secret): SHA-256 لكلمة مرور الإدارة
- `DOWNLOAD_SIGNING_SECRET` (Secret): سر عشوائي طويل
- `SITE_URL` (Variable): `https://puzstore.com`

توليد قيمة SHA-256 لكلمة مرور الإدارة:
```bash
printf %s 'كلمة-مرور-قوية-هنا' | sha256sum
```
على macOS استخدم:
```bash
printf %s 'كلمة-مرور-قوية-هنا' | shasum -a 256
```
وتوليد سر التنزيل:
```bash
openssl rand -hex 32
```

## 3) اربط الدومين puzstore.com
1. يجب أن تشتري/تملك الدومين أولاً؛ الدومين نفسه ليس مجانياً.
2. في Cloudflare Pages > Custom domains أضف `puzstore.com` واتبع تعليمات DNS.
3. حدّث `SITE_URL` إلى `https://puzstore.com` وأعد النشر.

## 4) إعداد Moyasar
1. افتح حساب تاجر / بيئة Sandbox في Moyasar.
2. احصل على Publishable Key وSecret Key.
3. اطلب تفعيل وسائل الدفع التي تريدها لحسابك: Mada وApple Pay وSTC Pay.
4. أكمل متطلبات التحقق التجاري والموقع وسياسة الاسترجاع وبيانات التواصل.
5. اختبر في Sandbox أولاً. لا تستخدم مفاتيح Live قبل موافقة Moyasar.
6. الدفع يستخدم Moyasar Payment Form داخل المتصفح؛ السيرفر لا يتعامل مع أرقام البطاقات. السيرفر يعيد جلب عملية الدفع بمفتاح سري ويتحقق من الحالة والمبلغ والعملة ووصف الطلب قبل إصدار رابط التنزيل.

مراجع Moyasar:
- https://docs.moyasar.com/guides/card-payments/basic-integration
- https://docs.moyasar.com/

## 5) الدخول للوحة التحكم وإضافة منتج
- افتح `https://puzstore.com/admin`.
- أدخل كلمة المرور التي أنشأت لها `ADMIN_PASSWORD_HASH`.
- أضف اسم المنتج ووصفه وسعره بالريال وارفع الملف.
- الملفات تُخزن في R2، وليس في قاعدة البيانات. الحد المطبق في هذه النسخة 25MB لكل ملف.
- رابط التنزيل مؤقت (48 ساعة) ولمرة واحدة في هذا الإصدار.

## 6) نشر تجريبي محلياً
ثبت Node.js ثم:
```bash
npm install
npx wrangler pages dev public
```
يجب ضبط D1 وR2 محلياً حسب معرّفات مواردك في Cloudflare؛ راجع دليل Wrangler/Pages Functions.

## نقاط مهمة قبل البيع الحقيقي
- غيّر كلمة مرور الإدارة إلى قيمة قوية ولا تشاركها.
- فعّل حماية إضافية للوحة الإدارة (Cloudflare Access) قبل التوسع.
- أضف سياسة خصوصية واسترجاع وشروط بيع ووسيلة تواصل واضحة.
- اختبر شراءً كاملاً ورفض الدفع وإعادة التوجيه قبل الإعلان.
- لا ترفع ملفات إعدادات تخص شخصاً آخر أو محتوى لا تملك حق إعادة بيعه.
- هذه نسخة تأسيسية تحتاج اختباراً أمنياً وتشغيلياً قبل استقبال مدفوعات حقيقية. لا تعتبرها مراجعة أمنية أو ضماناً لاستيفاء الأنظمة المحلية.
